# FR3 笛卡尔工作站

[English guide](README.md) · [产线开发计划 / Production development plan](docs/production-plan.md) · [架构与维护 / Architecture](docs/architecture.md)

这是一个基于 PySide6 的 FAIRINO FR3 软件原型，用于工具中心点标定、多个工件平面标定，以及保持工具姿态的 XYZ 定位。首次启动默认选择真实 FR3，但保持断开；程序会记住上次选择的模式。不会自动连接或运动。目前尚未包含自动取放循环及夹爪控制。

## 启动与语言切换

本程序位于 PickAndPlaceTilted 仓库的 `fr3-cartesian/` 子目录，与仓库根目录中的相机工作台分别运行。以下命令均在此子目录中执行。首次使用时，创建独立环境并安装固定版本 SDK：

```bash
/usr/bin/python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e .
.venv/bin/python tools/install_sdk.py
```

建议使用系统 Python，避免 Conda 与系统 Qt 原生库混用导致启动崩溃。Python 3.10+ 的其他版本可改用 `pip install -e '.[dev]'` 选择兼容依赖。Linux 桌面可能需要安装 `libxcb-cursor0`。随后运行：

```bash
.venv/bin/python -m fr3_cartesian
```

也可以先执行 `source .venv/bin/activate`，再运行 `python -m fr3_cartesian`。

窗口右上角的 **Language / 语言** 可即时切换 **English** 与 **简体中文**，不需要重启。用户选择会保存在 Qt 设置中；本机路径为 `~/.config/FR3Cartesian/Studio.conf`，下次启动自动恢复。

切换语言只更新界面和消息，不发送机器人指令，也不改变标定数值、工具姿态、运动使能状态或输入坐标。用户自定义的平面名称、文件路径、错误码以及 mm、°、% 单位保持不变。SDK 和操作系统的原始诊断详情保留原文，便于排查问题。

若仅需指定本次启动的语言，而不更改已保存的偏好：

```bash
.venv/bin/python -m fr3_cartesian --language zh_CN
.venv/bin/python -m fr3_cartesian --language en
```

## 仿真完整流程

1. 选择 **仿真器**，点击 **连接**。
2. 在 **工具标定** 页点击四次 **仿真：下一个接触姿态**，然后点击 **计算 TCP**。演示工具相对法兰的偏移为 `[0, 0, 120]` mm。点击 **应用 TCP 到此编号**。
3. 在 **工件平面** 页点击三次 **仿真：下一个平面点**，然后点击 **计算并添加平面**。示例平面带有倾斜，其 Z 轴不同于机器人基坐标的 Z 轴。
4. 在 **XYZ 控制** 页选择平面，点击 **锁定当前工具姿态**，确认各轴方向与行程范围，勾选确认项，再勾选 **启用笛卡尔运动**。
5. 点击 **+Z**，工具沿该平面的法向移动 1 mm。其余方向键沿平面的 X、Y 轴运动。也可以输入平面坐标 XYZ，执行绝对定位。

普通模式按住方向键时，最多移动设定步长（0.1–10 mm）；**松开即请求停止正在执行的当前步**，不再等待走完整步。**按住方向键连续步进** 模式固定每步 1 mm，只有仍然按住且上一步到位时才发送下一步。未发送的步进会直接取消。正常松开并确认机器人静止、程序停止后，保持连接、已验证 TCP 和姿态锁；实际停止响应取决于控制器和网络。按住平面方向键时切换窗口也会请求停止并取消运动使能，确认停止后保持连接。软件停止不等同于硬件急停。**停止 / Esc** 请求软件停止，并使当前连接失效。恢复操作需重新连接、应用 TCP 和锁定姿态。

## 连接真实机器人

控制器返回 **V3.8.25-QX**，内部软件版本为 **v3.8.5.1**。本地安装的官方 SDK 为 **v2.1.5 / 控制器 3.8.5**，固定至提交 `f2d762e37f0e9c18d63340eba5972bdb81159276`。下载地址和校验值见 `tools/install_sdk.py`。安装器会将被替换的 SDK 保存在 `vendor/fairino/Robot.py.previous`。

此版本将 `MoveL` 参数打包为一个扁平 XML-RPC 数组。此前的 3.8.2 SDK 发送 13 个独立参数，导致平面运动返回 `-502` 错误。更新后请关闭所有程序窗口并重新启动，将 **SDK 目录** 设为本项目的 `vendor` 目录。连接诊断会记录实际加载的 SDK 路径和版本。离线测试已验证运动请求的实际序列化格式，并确认失败指令不会自动重发。新版 SDK 尚未完成实机运动验证，公开标签没有完全对应的 QX 版本；若厂家提供专用 SDK，请在界面选择该包的父目录。

1. 连接机器人网络。默认 IP 为 `192.168.58.2`；SDK 3.8.5 使用 TCP 20003 发送 XML-RPC 指令，TCP 20004 接收状态。
2. 在 WebApp / 示教器中配置真实负载的质量、重心、安装方式、关节限位和碰撞保护。选择正确的已有负载配置。停止运行中的 Lua 程序，准备手动模式，并通过控制器使能机器人。
3. 首次启动默认选择 **真实 FR3**，但不会自动连接。填写 IP 和 SDK 目录（默认为项目中的 `vendor` 目录）并点击 **连接**。程序会记住上次选择的连接模式；切换模式会断开当前会话。连接操作只读取状态，不会自动使能、清除故障或运动。
4. 完成工具和平面标定后，进行笛卡尔运动时必须在控制器中选择已应用的工具。软件会在运动前检查工具编号和 TCP 偏移量。启用笛卡尔运动前，请在 **XYZ 控制** 页点击 **使用基坐标系工件 0**，或通过 WebUI 选择该坐标系。软件将平面目标转换为机器人基坐标，并指定 `user=0`，因此控制器所选坐标系必须一致。选择其他工件坐标系时，软件会在发送运动前拒绝操作，并保持连接。

软件停止依赖通信，不是安全级急停，断网时不能保证送达。请始终保留可操作的物理停止按钮，并通过小步移动验证现场间隙。软件行程范围只约束 TCP，不覆盖整条机械臂、工具和夹具。机器人本身的工作空间、关节限位、奇异点和碰撞约束仍然有效。

进行关节或基坐标系笛卡尔示教时，勾选 **启用示教点动控制** 并按住轴按钮；松开即发送停止指令。关节行程可设为 0.1°–10°，基坐标直线行程为 0.1–50 mm，基坐标旋转行程为 0.1°–10°。关节与 TCP 分别提供速度滑块及百分比输入，可设为 1%–10%，默认 3%。基坐标点动提供 X/Y/Z 与 RX/RY/RZ，不依赖工件平面标定；XYZ 标签页仍使用已标定的工件平面和锁定姿态。软件使用 FAIRINO `StartJOG(ref=0)` / `StopJOG(ref=1)` 控制关节，使用 `StartJOG(ref=2)` / `StopJOG(ref=3)` 控制基坐标系笛卡尔轴。后台状态读取期间松开按钮也不会丢失停止操作：尚未发送的点动会被取消，已发送的点动会紧接着发送停止指令。

如果连接时出现 `Connection refused`，说明控制器端口不可用或网络拒绝连接。软件会分别标明指令端口 20003 和反馈端口 20004。请检查控制器服务与网络，然后重新点击连接。首次连接失败不会发送停止指令；已建立会话之后发生故障，仍会请求停止并使会话失效。

FAIRINO 返回码 **74** 表示 **直线指令点错误**。控制器故障 **1/2** 表示 **直线目标点错误（含工具不匹配）**。请在官方 WebUI 中检查并复位故障，选择已标定工具和基坐标系工件 0 后重新连接。无需仅因此错误重新标定。11 月 18 日的只读检查发现，在当前姿态附近沿已保存 Pick plane 的六个方向移动 1 mm 均有一致的逆解与正解，当时控制器选择的是工件 1；该检查不验证实际运动路径，也不能证明坐标系不一致是唯一原因。实际 MoveL 拒绝或结果不确定的通信故障仍会请求停止并使会话失效，不会自动重发。

## 静态阵列取放原型

**4 取放** 标签页提供不依赖视觉和夹爪的静态路径配方。先在 **工件平面** 中选择已标定平面，再到 **XYZ 控制** 中锁定姿态并启用笛卡尔运动，然后选择阵列行并采集当前 TCP 到该工件的平面 X/Y/Z 坐标。仍可直接编辑坐标微调。默认阵列为 3 行 × 2 列，间距 30 mm；修改行列数时重新生成规则阵列并保留重叠单元格的已有编辑。按行优先顺序运动。

点动到固定放置位置后，将当前姿态采集为六轴机器人基坐标 TCP。选择每个阵列工件行，为其单独编辑过渡路径。点动到路径点后点击 **添加路径点**，将当前基坐标 TCP 采集到该工件路径中。检查界面显示的完整顺序并勾选确认项后再启动。单个工件去程为：取料点 → 该工件路径点 → 固定放置点；前往下一个工件时，按下一个工件路径点的逆序返回 → 下一个取料点。取料和放料点使用精确停止的 `MoveL`。中转路径点使用控制器端 `MoveL` 拐角平滑，控制器会圆滑这些拐角；最终取/放料点使用精确停止。平滑可能切入示教拐角内侧，请确保机械臂和工具的完整运动包络与周围物体保持间隙。相邻审核位姿仍须不超过 100 mm。取料点必须位于当前平面行程范围内；基坐标系中转点和目的地可在平面范围之外，并保留各自示教姿态。取料点使用 XYZ 控制中锁定的姿态。普通 XYZ 点动仍受平面限位约束并保持锁定姿态。旧版共享路径会迁移为每个工件各自独立的副本。

中转路点使用 FAIRINO `MoveL` 拐角平滑，平滑半径不超过 10 mm，且不超过相邻线段长度的四分之一。最后的取/放料目标使用 `blendR=-1` 阻塞并精确停止。每批动作都会等待最新反馈确认到达终点且机器人静止后才继续。**取消序列**会执行 STOP 并断开会话；再次运动前需要重新连接并验证 TCP。整个序列期间也可使用普通 **STOP / Esc**。启动前请检查现场间隙及机械臂、工具的完整运动包络。本原型不控制夹爪、不确认工件、不执行自动接近/撤离、不接入视觉，也不规划无碰撞路径。它仅演示按顺序移动到坐标，不是可无人值守的产线循环。

## 工具中心点标定

选择工具上能够重复接触的实际工作点，例如夹爪的取料中心；准备一个固定、刚性的参考点。

让工具尖端从至少四种明显不同的姿态接触同一个参考点。姿态应绕两个不同方向变化；不要移动参考点或更换工具。可以使用示教器、拖动示教或软件中的关节步进控制。**每次采集前必须退出拖动模式并等待机器人静止。**

算法使用最小二乘求解：

```text
法兰旋转矩阵[i] × TCP偏移 + 法兰位置[i] = 固定参考点
```

计算结果包括 TCP 的 XYZ 偏移、接触残差 RMS、最大残差和条件数。姿态变化不足或残差超过设定阈值时会拒绝结果；默认最大残差为 0.5 mm。可以采集超过四个姿态。

此方法只标定工具中心点的**平移偏移**，工具旋转设为 `[0, 0, 0]`，工具轴与法兰对齐。仅靠接触同一个点无法确定工具轴的旋转方向。完整六点工具轴标定尚未实现；当前平面 XYZ 控制通过锁定基坐标中的工具姿态实现固定姿态运动。

选择工具坐标系编号（1–14）、工具 ID 和已有负载配置编号。点击 **应用 TCP** 会调用官方 SDK 的 `SetToolList` 和 `SetToolCoord`，覆盖控制器中该编号的定义。修改接触点会使工具标定和已有工件平面失效，需要重新标定。

## 工件平面与 XYZ 控制

应用标定后的工具后，依次采集：

1. **O**：工件平面的原点。
2. **X**：沿正 X 方向的另一个点，与原点至少相距 10 mm。
3. **Y**：位于 XY 平面正 Y 一侧的点，与原点至少相距 10 mm。

软件建立右手正交坐标系，正 Z 由 `X × Y` 决定。请确认其指向离开工件表面的方向。三点接近共线时无法确定平面，软件会拒绝计算。可以分别建立取料、放料等多个平面。

平面先保存在本地。只有执行下述明确的应用操作，才会更新控制器的工件坐标系编号。软件按以下方式换算：

```text
基坐标目标位置 = 平面原点 + 平面旋转矩阵 × 平面XYZ坐标
```

**WebUI 的 Wobj 点动沿控制器当前已应用的工件坐标系运动。** `Tool1, Wobj1` 表示工具编号 1 和工件编号 1。仅保存本地平面或应用 TCP 不会上传平面。同步步骤：

1. 连接并验证或应用已标定 TCP，在 **工件平面** 页选择已保存平面。
2. 选择 **目标控制器 Wobj 编号**（1–14），检查预览中的基坐标原点与 RX/RY/RZ。这些角度定义平面坐标系，与锁定的 TCP 姿态不同。
3. 勾选 **应用平面到控制器** 按钮上方的覆盖确认，再点击按钮。按钮灰色时，其上方提示及工具提示会说明首个未满足条件：连接、所选平面、实时反馈、故障或停止状态、运行中的程序、TCP 验证或覆盖确认。程序通过 `SetWObjList` 和 `SetWObjCoord` 覆盖并选择该编号，参考系为 0（基坐标）。机器人必须静止，无运行中的程序或故障；此操作不发送运动，也不自动复位故障。
4. 等待验证成功消息。程序检查当前 Wobj 编号并回读平移和旋转，不会自动重试失败的写入。在 WebUI 中选择 **Wobj 点动**，使用相同工具和工件编号。

目标编号偏好会随标定保存；覆盖确认和本次验证状态不会在重新连接后恢复。启动、连接以及本地保存或加载都不会上传坐标系。此功能已通过仿真与官方 SDK 的 XML-RPC 序列化测试；实际点动方向以及控制器重启后的保留情况仍待实机验证。

使用本程序的 **XYZ 控制** 时，请点击 **使用基坐标系工件 0**，再重新锁定姿态并确认行程。方向键仍将所选本地平面换算到基坐标；切换到基坐标不会删除已保存的 Wobj 编号。工件页预览显示的是 **坐标系定义**；WebUI 点动时显示的六个数是 **当前 TCP 位姿**，不能仅凭这些数判断 Wobj 的存储定义。

参考：[WebUI Wobj 点动](https://fairino-doc-en.readthedocs.io/latest/CobotsManual/teaching_pendant_software.html) 与 [工件坐标系 SDK 接口](https://fairino-doc-en.readthedocs.io/latest/SDKManual/PythonRobotCommonSettings.html)。

在本次实测 FR3 上，TCP 和法兰反馈均相对于当前 Wobj。程序在实时查询法兰位姿前后读取当前坐标系并确认未发生变化，将完整法兰位姿转换为基坐标后，再结合当前 TCP 偏移计算工具位置。因此，即使切换 Wobj，新采集点仍使用同一基坐标参考。平面目标转换至机器人基坐标后，通过 `MoveL(tool=所选工具编号, user=0)` 发送，控制器必须选择基坐标系工件 0；仅工具编号和 TCP 偏移量一致还不够。点击 **使用基坐标系工件 0** 会明确调用 `SetWObjCoord(0, [0,0,0,0,0,0], 0)`，并回读验证当前编号和偏移。此操作不发送运动，保留 Wobj 1–14，取消运动使能并要求重新锁定姿态和确认各轴方向及行程。程序启动或连接时不会自动切换坐标系；此按钮也不会上传已保存平面。每条平面运动前还会检查当前基坐标偏移是否为零。每次运动保持锁定的工具姿态。切换平面或进行关节示教后，需要重新锁定姿态。

启用运动前设置各轴最小值与最大值。起点和终点必须同时位于范围内；单次绝对定位最长 100 mm。默认速度为控制器速度的 3%，最高可设为 10%；该值为百分比，**不是 mm/s**。当前没有自动抬升、接近、绕障或夹爪动作流程。

如果执行 **移动到 XYZ (0, 0, 0)** 时提示当前 TCP 超出平面行程限制，表示目标可能有效，但起点位于允许范围之外。XYZ 控制页会在行程设置旁显示当前位置检查结果，拒绝消息包含超限轴、当前坐标和允许区间。请使用示教控制回到目标工件附近，再重新锁定姿态。原点是已保存的工件原点，不是当前 TCP。程序不会自动扩大行程限制，单次 100 mm 的限制仍然有效。

SDK 在独立进程运行，同一时刻只允许一条指令批次。取/放料终点使用精确停止的 `MoveL`；中转路点使用带正拐角平滑半径的 FAIRINO `MoveL`，最终取/放料点使用 `blendR=-1`。软件会等待最新反馈确认终点到位且机器人静止后，才允许下一步。状态过期、故障或超时会中止当前会话，软件不会自动重试结果不确定的运动指令。

若在发送任何运动指令之前，因目标或工具验证不通过而拒绝运动，程序会取消笛卡尔使能并说明原因，但保持连接。故障、状态过期、通信失败，以及发送运动后的错误仍触发停止并断开连接。被拒绝的指令不会自动重试。

点击停止或断开连接会通过独立通信请求 `ImmStopJOG` 和 `StopMotion`，并使当前连接失效。关节 / 基坐标系点动期间窗口失去焦点时会发送普通 `StopJOG` 停止指令并保持连接。笛卡尔直线运动进行中失去焦点会停止运动并断开；空闲时失去焦点只会取消笛卡尔使能，不会断开连接。

## 修复旧版本采集的平面

旧版本将 Wobj 相对的法兰反馈误认为基坐标反馈。如果采集时选择了非零 Wobj，随后把该平面作为基坐标定义上传，就会重复应用工件变换。这解释了工具接近原点时 WebUI XYZ 仍有巨大偏移，以及 Wobj 点动方向不符的问题。只读诊断依据与适用范围记录在[坐标系问题说明](docs/coordinate-frame-fix.md)中。

由于无法确认每个旧点采集时的参考系，新版本保留旧数据，但禁止使用这些平面。请只重新示教平面；现有 TCP 偏移可保留并与控制器核对。

1. 关闭所有旧程序窗口，启动新版本。连接并核对保存的 TCP；仅在不匹配时点击 **应用已保存的 TCP**。
2. 在 **XYZ 控制** 页点击 **使用基坐标系工件 0**。此明确选择不发送运动。修复后也支持在其他 Wobj 下采集，但使用基坐标 0 更便于核对。
3. 在 **工件平面** 页选中旧平面，点击 **删除平面**，再点击 **清空点位** 清除旧草稿。这些操作不会清除 TCP 标定。
4. 静止时重新采集 O、X、Y，点击 **计算并添加平面**。选择三点顺序，使正 Z 指向离开工件表面的方向，并检查新的基坐标预览。
5. 若使用 WebUI Wobj 点动，明确将新平面应用到目标编号，例如 Wobj1。控制器中已有的错误定义在替换之前仍然存在。选择正确工具和 Wobj 后，工具位于示教 O 点时，WebUI XYZ 应接近零；RX/RY/RZ 是工具相对平面的姿态，不必为零。
6. 若使用本程序 XYZ 控制，再次选择 **使用基坐标系工件 0**，锁定当前姿态，核对方向与行程，再启用运动。

## 保存和加载

程序会将更改自动保存至项目目录中的 `calibration-session.json`，启动时自动恢复。保存内容包括 TCP 原始接触点与计算结果、全部工件平面的名称与参考点、尚未完成的平面名称与采集点、当前所选平面、静态取放阵列尺寸和单元坐标、固定基坐标 TCP 放置点、每个阵列工件各自独立的六轴基坐标 TCP 过渡路径，以及 XYZ 行程限制、步长、速度、按住模式、目标坐标和上次姿态参考值。停止修改片刻后自动保存，关闭窗口时也会立即保存。文件采用原子替换，避免写入中断截断上次保存；保存失败会在日志中提示。

首次更新启动时，若没有自动保存文件，会导入项目中已有的 `calibration.json`，并保留原文件。仍可通过“保存标定…”与“加载标定…”手动备份或交换配置。新文件使用 schema 3，除 XYZ 设置外，还记录 TCP 样本、平面点和未完成采集点的坐标参考，并兼容读取 schema 1、2 文件。缺少参考信息的旧实机测量保留为 `legacy_workpiece_unknown`，对应平面禁止上传和运动，新采集点也不能混入旧草稿；加载时会根据原始采集点重新计算 TCP 与平面。

自动恢复不会连接机器人、写入控制器或恢复运动使能。连接后（或连接期间加载文件后），程序会读取当前工具编号与全部六项 TCP 偏移，和保存的标定进行比较，容差为 0.001 mm/度。匹配时直接确认 TCP，不写入控制器；不匹配时，可在 **XYZ 控制** 中点击 **应用已保存的 TCP**，或在工具标定页应用。此操作会更新保存的工具编号并等待控制器确认。XYZ 页显示确认状态；当前工具编号或偏移变化会取消确认。

保存的姿态只显示为参考值，不会自动成为有效姿态锁。确认 TCP 后，请锁定当前姿态、确认坐标轴与行程限制，再启用运动。仿真标定不能应用于真实机器人；保存文件不能自动识别夹具移动或工具更换。

程序集中提供 TCP 标定、工件平面、界面示教点动及已标定 XYZ 定位，已移除摇杆示教页。基坐标点动面板提供独立的 **TCP 点动速度** 滑块与百分比输入（1–10%，默认 3%），与关节点动速度分开设置。点动速度及行程上限随标定会话保存。

## 环境与验证

Ubuntu 上应明确使用系统 Python 创建环境，避免 Anaconda 的桌面库与系统 Qt 依赖冲突：

```bash
/usr/bin/python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e .
.venv/bin/python tools/install_sdk.py
```

本机已将 `.venv` 修复为 Ubuntu Python 3.12，旧 Anaconda 环境保存在 `.venv-conda-backup/`。未修改系统或全局 Conda 设置。

运行测试及桌面启动检查：

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m fr3_cartesian --language zh_CN --smoke-test
```

测试包括中英文完整仿真流程、语言切换不发送机器人指令、不改变标定与坐标、偏好持久化、错误消息跨进程传输、翻译参数一致性、关节与基坐标系点动的限位及松开停止、轮询期间的停止调度、连接模式切换及点动就绪条件。实机只读反馈已验证；标定精度、QX 完整运动兼容性、实机点动与物理停止仍需验证。

### Three.js FR3 可视化模拟器

可选的浏览器预览位于 `simulator/`。它使用 FAIRINO FR3 v6 STL 连杆模型和 URDF 关节原点，支持载入 Studio 的 `calibration-session.json` 并播放已保存的静态取放路径。在项目目录中启动：

```bash
cd simulator
python3 -m http.server 8765
```

然后在 Chrome 打开 `http://localhost:8765`。导入正在使用的 Studio 会话文件 `../calibration-session.json`，或载入内置的 3 × 2 示例。此预览仅在浏览器中运行，不连接机器人 SDK。阻尼数值逆运动学仅用于直观查看路径，不能验证可达性、碰撞、动力学或控制器运动。

FR3 v6 STL 和 URDF 模型来自 [FAIR-INNOVATION/frcobot_ros2](https://github.com/FAIR-INNOVATION/frcobot_ros2/tree/main/fairino_description)。该仓库的 `fairino_description/package.xml` 当前将许可证标记为 `TODO`；重新分发模型资产前请确认上游授权条款。
